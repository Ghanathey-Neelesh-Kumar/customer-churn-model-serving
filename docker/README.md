# Docker lecture notes

The root `Dockerfile` is the canonical image definition.

Teaching order:

1. Explain image layers and build context.
2. Explain why requirements are copied before source files.
3. Explain non-root execution.
4. Build the image.
5. Run and test locally.
6. Inspect logs and health.
7. Tag with an immutable version.
8. Push to ECR.
9. Remove local and cloud resources after the demonstration.
